# TelegramAutoposter 1.16.2

Telegram-бот для автоматической рассылки постов в супергруппы.

## 🚀 Возможности

- Автоматическая рассылка постов с фото/видео
- Поддержка Markdown и форматирования из Telegram-клиента
- 👥 Скрытые отметки всех участников (невидимые упоминания)
- 📨 Посты-пересылки: форвард из канала со всем форматированием
- 🧵 Темы форумов: выбор из списка или вручную
- 🐢 Автосинхронизация КД под слоумод канала (впритык, с минимумом)
- 🎨 Цветные кнопки (Bot API 9.4) и неактивные индикаторы (10.3)
- Индивидуальные посты для каждого канала
- Настройка интервала рассылки (общий и на чат, минимум-пол)
- Независимый таймер для каждого чата + отчёт о доставке
- Таймеры переживают перезапуск (хранятся в БД)
- Повторные попытки отправки при сбоях
- ⚙️ Настройки: журнал отправок в отдельный чат (#log), отчёты, вкл/выкл всех чатов
- Фильтры чатов: все / включённые / выключенные
- ☑️ Мультивыбор чатов: вкл/выкл, отметки, интервал пачкой
- ❌ Отмена любого ввода, чистый чат без мусора
- Автовозобновление рассылки после перезапуска + watchdog
- Управление через Telegram бота
- Автоматическое обновление с GitHub

## 📋 Требования

- Python 3.11+
- Telegram API credentials (API_ID и API_HASH)

## 🚀 Установка

### Шаг 1: Клонировать репозиторий

```bash
git clone https://github.com/zdebryrp/TelegramAutoposter.git
cd TelegramAutoposter
```

### Шаг 2: Создать виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows
```

### Шаг 3: Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4: Настроить `.env` файл

```bash
cp .env.example .env
# Отредактировать .env файл с вашими данными
```

### Шаг 5: Получить API credentials

1. Зайти на [my.telegram.org](https://my.telegram.org/auth)
2. Войти с помощью телефона
3. Перейти в **API tools**
4. Создать новое приложение
5. Скопировать `API_ID` и `API_HASH`

### Шаг 6: Запустить бота

```bash
python main.py
```

## ⚙️ Конфигурация

В файле `.env` указать:

```env
TOKEN=ваш_токен_бота_здесь
ADMINS=8295697775
DIR=
API_ID=ваш_api_id_здесь
API_HASH=ваш_api_hash_здесь
```

### Переменные

| Переменная | Описание |
|------------|----------|
| TOKEN | Токен бота (получить у @BotFather) |
| ADMINS | ID администраторов (через запятую) |
| DIR | Путь к файлам медиа |
| API_ID | ID приложения с my.telegram.org |
| API_HASH | Hash приложения с my.telegram.org |

## 📱 Использование

1. Открыть бота в Telegram
2. Отправить команду `/start`
3. Использовать клавиатуру для управления
